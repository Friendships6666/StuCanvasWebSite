## 什么是 StuCanvas？

StuCanvas 是一款专为科学可视化设计的高性能开源 C++ 引擎。通过充分利用 Vulkan API，它有效解决了传统 WebGL/OpenGL 渲染中常见的 CPU 性能瓶颈。

## 核心特性

- **Vulkan 驱动**：原生 GPU 加速。
- **跨平台**：一次编译，即可运行于 Arch Linux、Windows 和 macOS。
- **现代 C++**：基于 C++23 标准构建。
